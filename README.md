# Roulette Bot

**Roulette Bot** — расширение для Google Chrome для автоматизации стратегий игры в рулетку с русскоязычным интерфейсом.

Поддерживаются стратегии **Dozens** и **Catch X Match**, отслеживание результатов, управление ставками и просмотр расчётной статистики.

Приложение работает через защищённое соединение с сервером. Для использования необходима действующая лицензия.

## Скачать Roulette Bot

**[Скачать последнюю версию](https://github.com/spintracker/Roulette-BOT-Downloads/releases/latest)**

Загрузите файл `roulette-bot-release-vX.Y.Z.zip` из раздела Releases.

## Установка

1. Скачайте ZIP-архив и распакуйте его в отдельную папку.
2. Откройте Google Chrome.
3. Перейдите на `chrome://extensions`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите папку, содержащую `manifest.json`.
7. Откройте Roulette Bot через меню расширений Chrome.

Не удаляйте папку установленного расширения.

## Активация лицензии

1. Получите код активации у администратора.
2. Откройте раздел **Подписка**.
3. Выберите игровой стол, для которого выдан код.
4. Введите код активации.
5. Нажмите **Активировать на месяц**.

После активации появится информация о статусе подписки и дате окончания.

**Условия подписки:**

- Одна лицензия — одна установка расширения и один игровой стол.
- Код активации одноразовый и действителен 14 дней.
- Срок подписки — один календарный месяц с момента активации.
- При продлении повторная активация не требуется.
- Регистрация аккаунта не нужна.

## Использование

После активации:

1. Откройте поддерживаемый игровой стол.
2. Выберите его в Roulette Bot.
3. Включите отслеживание результатов.
4. Выберите стратегию и настройте параметры.
5. Проверьте соединение и состояние бота.
6. Для начала работы нажмите **Запустить**.

Управление осуществляется через кнопки **Запустить**, **Пауза** и **Сбросить**.

## Обновление

1. Остановите бот.
2. Скачайте новую версию из раздела Releases.
3. Замените файлы в существующей папке расширения.
4. Откройте `chrome://extensions` и нажмите **Обновить**.
5. Перезагрузите страницу казино.
6. Проверьте подключение и лицензию.

Не удаляйте установленное расширение без необходимости: потеря ключа устройства может потребовать обращения к администратору.

## Поддержка

При возникновении ошибки откройте раздел **Подписка** и нажмите **Скопировать отчёт для поддержки**.

Передайте отчёт администратору вместе с описанием проблемы.

## Статус разработки

Roulette Bot находится на этапе тестирования. Возможны ошибки выполнения и ограничения совместимости с игровыми интерфейсами.

Расчётная статистика не является подтверждением фактических результатов казино. Используемые стратегии не гарантируют прибыль.
